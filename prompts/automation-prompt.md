# 自动化任务 Prompt 模板 — 每日诗歌推荐

> 用途：将本 Skill 接入 WorkBuddy / Codex / Claude 等平台的定时任务（Automation）。
> 使用前请将下方所有 `{PROJECT_DIR}` 占位符替换为你的实际项目目录绝对路径。

---

请完成每日诗歌推荐任务：

## 一、读取历史记录
读取文件：`{PROJECT_DIR}/history.json`
如果文件不存在，创建空数组 `[]`

## 二、选择一首古代著名诗歌
**选择规则：**
1. 优先从唐诗、宋词、先秦诗歌、汉乐府等古代诗歌中选取
2. 优先选择流传度高、作者著名、入选课本或广为人知的经典诗作
3. **严格避免选择历史记录中已存在的诗歌**（比较诗歌名称和作者）
4. 避免选择现代诗

**诗歌解读严谨性要求（必须遵守）：**
- 必须基于史实：创作背景、诗人经历、历史事件必须准确
- 引用可靠：历代评价需注明出处（朝代 + 评家姓名）
- 手法分析准确：修辞手法、表现手法的分析必须符合文学理论
- 逐句解读完整：每句诗必须包含字面意思、修辞手法、深度解读
- 避免编造：不确定的内容需标注"待考证"或省略

## 三、生成完整的诗歌解读HTML文件
读取模板文件：`{PROJECT_DIR}/templates/poem-template.html`

**配色规范（必须遵守，新中式文雅山水风）：**

### 固定配色（所有诗统一）
- body背景：宣纸白 #fcfaf2（不要用冷灰蓝渐变）
- 诗人卡片：黛蓝渐变 linear-gradient(135deg, #2c4f6c 0%, #1f364d 100%)
- 标题色：深墨蓝 #1a365d
- 线条颜色：黛蓝 #2c4f6c（绝对禁止使用科技蓝 #3498db）
- 推荐阅读区域：沉香茶色 #f4f0ea 底，深茶色 #5c4738 边框
- 情感曲线三阶段：晚霞金 #f9f1db / 竹青 #edf6f0 / 暮色灰蓝 #f0f4f8

### 核心名句配色（根据诗歌意境选择）
根据所选诗歌的意境，从 SKILL.md 的意境配色表中选择最合适的一个（黄鹤楼/游子吟/虞美人/短歌行/声声慢/望岳/登鹳雀楼/水调歌头/琵琶行/春望/木兰诗）。

**绝对禁止使用的颜色：**
- ❌ 粉红渐变 #f093fb → #f5576c
- ❌ 紫罗兰渐变 #667eea → #764ba2
- ❌ 荧光绿 #11998e → #38ef7d
- ❌ 科技蓝 #3498db
- ❌ 冷灰蓝渐变背景 linear-gradient(135deg, #f5f7fa 0%, #e8ecf1 100%)

根据模板填充完整内容，包括：诗人信息、创作背景、时代背景、情感曲线、逐句深度解读、艺术特色、千古名句、历代评价、阅读建议。

**保存文件：**
- 文件名格式：`YYYY-MM-DD_诗歌名_深度解读.html`
- 保存路径：`{PROJECT_DIR}/每日诗歌推荐/`

## 四、更新历史记录
将本次推荐的诗歌添加到 history.json 中（date/poem/author/dynasty/era/file/tags）。

## 五、生成学习汇总报告
更新 `{PROJECT_DIR}/学习汇总.html`

## 六、输出确认信息
任务完成后，输出：本次推荐的诗歌名称和作者、已学习诗歌总数、按朝代分布统计、HTML文件保存路径。

**重要提醒：**
1. 诗歌解读必须严谨准确，基于可靠史料
2. 核心名句卡片必须使用上述配色方案中的对应颜色，不能使用粉红渐变
3. 所有引用需注明出处

## 异常处理
- history.json 不存在 → 创建空数组 []
- JSON 格式损坏 → 备份后重建
- 诗歌与历史重复 → 重新选择
- 解读信息不足 → 跳过，选择下一首
- HTML 渲染失败 → 重试一次，降级 Markdown
- 每次执行后必须确认 history.json 写入成功（历史记录完整性是去重机制的生命线）
